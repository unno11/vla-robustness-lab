# 技术路线与验收

| 里程碑 | 交付物 | 验收条件 | 状态 |
| --- | --- | --- | --- |
| 仓库与流程 | 文档结构、CI、来源记录、Issue | 仓库静态检查通过，验证范围明确 | 初始化 |
| 首个真实rollout | 隔离环境、锁文件、运行入口和接口追踪 | 固定任务初态真实闭环、结果和显存证据，无接口断言错误 | CPU 物理诊断已通过；相机与策略待完成 |
| 单套件基线 | 冻结协议、逐回合结果与报告 | 完成所有计划回合，所有失败与错误可追踪 | 待完成 |

| 轻量训练适配 | SmolVLA资源实测、匹配训练对照 | 有训练证据、独立验证和闭环评测；负结果同样有效 | 可选，未开始 |
